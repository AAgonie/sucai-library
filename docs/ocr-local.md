# 本地 OCR 安装与使用

OCR（Optical Character Recognition，光学字符识别）在部署电脑本地运行，不会把图片上传到云端。识别出的文字写入本机 SQLite（轻量级文件数据库），可用于网站搜索、标题提取和自动审查。

## 安装

在项目根目录执行：

```powershell
python -m pip install paddlepaddle==3.2.0 -i https://www.paddlepaddle.org.cn/packages/stable/cpu/
python -m pip install -r backend\requirements-ocr.txt
```

安装后关闭旧的服务窗口，再运行：

```powershell
.\start.cmd
```

局域网服务机请改用：

```powershell
.\start-nas.cmd
```

首次 OCR 会下载模型并建立本地缓存，通常比后续识别慢。模型下载必须由实际运行服务的 Windows 账号完成；换账号或换电脑会使用新的缓存。

## 性能与稳定性

- 默认使用 PP-OCRv5 mobile 轻量模型和 12 个 CPU（Central Processing Unit，中央处理器）推理线程。
- 可在启动前设置 `PHOTO_WEB_OCR_CPU_THREADS`，范围为 1 至 16。例如：

  ```powershell
  $env:PHOTO_WEB_OCR_CPU_THREADS = "12"
  .\start-nas.cmd
  ```

- OCR 引擎在一个服务进程内串行运行。这是为了避免 PaddleOCR 原生运行时并发造成崩溃或使其他网页请求失去响应；提高线程数不等于同时启动多个 OCR 任务。
- 如需尝试偏精度的 medium 模型，可在启动前设置 `PHOTO_WEB_OCR_MODEL_PROFILE=medium`。该模式通常更慢，应先用少量图片测试。

## 使用方式

1. 打开网站，确认健康检查正常。
2. 单张识别：打开图片详情，选择“识别文字”。
3. 批量识别：在主界面选中图片后，选择“识别所选文字”。
4. 统一处理：进入“识别中心”，先检测未识别项目，再提交识别任务。
5. 完成后可以直接以识别文字搜索；如图片已生成比例派生版本，OCR 结果会同步到同一素材记录。

## 自动隐藏规则

若 OCR 原始文本中识别到成对书名号（例如 `《内容》` 或 `〈内容〉`），服务会将该图片记录标记为隐藏，并在任务结果与网页提示中报告原因。隐藏不会删除源文件；在“显示隐藏图片”模式下仍可审查和恢复记录。

## 无效词

“识别中心”中的 OCR 无效词用于清洗识别标题。词库保存在本机运行数据目录，新增或修改后只影响之后重新识别的图片；已有结果不会自动重算。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示“PaddleOCR 未安装” | 确认在启动服务的同一台电脑、同一个 Python 环境中执行安装命令，然后重启服务。 |
| 首张图片很慢 | 等待模型首次下载和初始化完成；从第二张开始再比较速度。 |
| 批量时网站响应变慢 | 不要启动第二个服务或第二个 OCR 进程；先减少批量规模，等待当前任务完成。 |
| 识别为空 | 检查文字大小、对比度、压缩质量和遮挡情况；必要时维护无效词后重试。 |
| 多台电脑结果不一致 | 所有浏览器必须访问同一个服务地址。每台电脑分别启动服务会使用不同的本地数据库。 |
